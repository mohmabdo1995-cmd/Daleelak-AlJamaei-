# دليلك الجامعي - جامعتك في جيبك 🎓

دليل رقمي شامل للطلاب الجامعيين يساعدهم على التأقلم مع الحياة الأكاديمية، تنظيم المحاضرات، تصفح المواد الدراسية، والتذكيرات الفورية عبر التلجرام وإشعارات المتصفح.

---

## 🌟 الميزات الرئيسية

- **الصفحة الأولى (Landing Hero)**: واجهة ترحيبية بتصميم عصري ورسومات متحركة مع زر "دخول".
- **الصفحة الرئيسية (Main Dashboard)**: تتضمن الكروت التفاعلية الثلاثة:
  1. **معلومات عن الكلية والمواد**: الساعات المعتمدة، التقييم، ونصائح الطلاب المستجدين.
  2. **مصادر الدراسة والمقررات**: الأطلس الطبي والكتب والمقررات الأساسية (*Anatomy*, *Physiology*, *Biochemistry*, *Microbiology*, *Pathology*, *Pharmacology*).
  3. **التنظيم والتذكير**: نظام جدول المحاضرات التفاعلي (إضافة، تعديل، حذف، فلترة، بحث) وتخزين دائم مع تنبيهات المتصفح المباشرة.
- **ربط التلجرام (Telegram Bot)**: وصول مباشر ورسمي لبوت التلجرام `http://t.me/Daleelak_AlJamaei_bot`.
- **تطبيق ويب تقدمي (PWA)**: دعم العمل بدون إنترنت، الملف التعريفي `manifest.json` و`sw.js` وإمكانية التثبيت على الهاتف والجهاز.
- **أدوات إضافية**: حاسبة المعدل التراكمي (GPA Calculator) ومؤقت التركيز والدراسة (Pomodoro Timer).
- **تصميم فاخر ودعم RTL**: دعم كامل للغة العربية، النمط الداكن/الفاتح، وألوان مريحة للعين.

---

## 🚀 التشغيل المحلي والتطوير

1. **تثبيت التبعيات**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

3. **بناء المشروع للإنتاج**:
   ```bash
   npm run build
   ```

---

## 📦 النشر والرفع (Deployment)

المشروع جاهز تماماً للنشر على منصات الاستضافة المختلفة:

- **Vercel / Netlify / Cloudflare Pages**: قم برفع كود المشروع واختيار الأمر `npm run build` ومجلد المخرجات `dist`.
- **Firebase Hosting**: قم بتشغيل `firebase deploy` بعد ربط المشروع بالمجلد `dist`.
